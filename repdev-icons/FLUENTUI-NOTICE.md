RepDev toolbar and menu glyphs derived from Microsoft Fluent UI System Icons.

Source package: `@fluentui/svg-icons` version `1.1.324`
Repository: https://github.com/microsoft/fluentui-system-icons
License: MIT

The generated runtime assets keep RepDev's existing `small-*` action naming so
the SWT UI can load them without code-level action mapping changes.

Current runtime asset set:

- `small-name.svg`: 16 x 16 logical icon canvas for SWT runtime rasterization
- `small-name-large.svg`: 24 x 24 logical icon canvas for the in-app large icon mode

Branding assets such as the RepDev monkey icon, EXE icon, and About logo remain bitmap-based.
